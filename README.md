# Myspoti extensions

The official extension repository for [Myspoti](https://github.com/kota-zo/myspoti): small
JavaScript extensions (lyrics sources, audio and download sources, reactions to the song playing,
access to your Spotify account) that Myspoti runs in a sandbox. Each one is reviewed here by pull
request before it is listed.

An extension can only do what its manifest asks and you accepted when installing. Myspoti shows
the list of rights, and a warning with the author's reason for each sensitive one, before anything
is installed.

## Use it in Myspoti

This repository is the one Myspoti offers by default. To add it by hand (or to check what the app
reads), the address of the index is:

```
https://raw.githubusercontent.com/kota-zo/myspoti-extensions/main/index.json
```

`index.json` lists every extension with its package (`dist/<id>-<version>.zip`), the package's
SHA-256 (Myspoti checks it before reading anything) and the rights it asks. It also holds the
`blocked` list: extensions every Myspoti turns off (see [REPORTING.md](REPORTING.md)).

You can also add any other repository, at your own risk: the same layout works anywhere.

## Submit an extension

Read [CONTRIBUTING.md](CONTRIBUTING.md) and [POLICY.md](POLICY.md), then open a pull request that
adds `extensions/<id>/`. Authors' documentation (manifest, hooks, permissions, the desktop runner
`myspoti-ext`) is in Myspoti's
[docs/extensions/API.md](https://github.com/kota-zo/myspoti/blob/main/docs/extensions/API.md).

## Report an extension

A malicious or abusive extension, a copyright or DMCA/DSA notice: see [REPORTING.md](REPORTING.md).

## Layout

```
extensions/<id>/      manifest.json, main.js, README.md, LICENSE, optional icon.png: the source
dist/<id>-<version>.zip   the packages, built by scripts/build_index.py (never edited by hand, never changed once published)
index.json            the repository index Myspoti reads (generated)
blocked.json          extensions to turn off everywhere (edited by maintainers, copied into index.json)
scripts/build_index.py    validation, packaging, index and the table above (Python 3, standard library only)
```

`dist/` and `index.json` are committed on purpose: Myspoti downloads them straight from the raw
file URLs, with no build server or release step in between. Packages are built deterministically
(fixed file order and dates), so anyone can run `python3 scripts/build_index.py --check` on a
clone and get the same SHA-256 as the one in the index.
